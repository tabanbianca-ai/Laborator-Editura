# Public Domain Validation

`PUBLIC_DOMAIN` must be verified and evidenced. It is not an assumption.

Required evidence:

- Author.
- Jurisdiction.
- Relevant dates.
- Source.
- Edition.
- Translation status.
- Added editorial elements.
- Verification result.
- Proof/evidence.

Rules:

- A public-domain original Work does not automatically make a modern translation public domain.
- Introductions, illustrations, annotations, covers, layout, audio narration, and edited editions may have separate rights.
- Public-domain status may allow editing, translation, and publication of the original Work only after validation.
- Contribution rights continue to be recorded for added editorial work.
