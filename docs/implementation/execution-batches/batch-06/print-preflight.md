# Print Preflight

Print preflight checks readiness for print outputs.

Checks include:

- trim size
- bleed
- margins
- cover requirements
- image resolution
- color profile
- font embedding
- crop marks
- print provider profile

Provider profile types:

- GENERIC_PRINT
- PRINT_ON_DEMAND
- AMAZON_KDP
- INGRAM
- LOCAL_PRINTER
- CUSTOM
