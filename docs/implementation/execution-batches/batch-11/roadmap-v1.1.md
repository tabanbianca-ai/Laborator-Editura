# Roadmap v1.1

Status: Backlog redirection only  
Owner: Product Governance

## Rule

Features that are desirable but nonessential for v1.0 must move to the v1.1 backlog without deleting their specification history.

## Candidate v1.1 Backlog Themes

- deeper provider integrations;
- advanced payment and commerce workflows;
- advanced analytics and dashboards;
- automated external APM integrations;
- full cloud backup provider integrations;
- production-grade SBOM automation if not completed in RC1 pipeline;
- advanced accessibility remediation automation;
- expanded device and browser support after tested evidence exists;
- additional AI agents or provider models only after RC stabilization.
