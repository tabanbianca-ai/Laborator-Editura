# Project Isolation

## Existing Project Scope

Project, document, segment, translation, export, workflow, rights, publishing,
library, research, collaboration, and media repositories already use
organization-scoped runtime database access.

## Batch 02 Role Scope Foundation

Role assignments can now represent project, publication, and resource scope in
addition to organization scope.

## Enforcement Rule

Until a controller or service has explicit project-scoped policy metadata, the
existing organization-scoped authorization and service-specific role checks
remain authoritative.
