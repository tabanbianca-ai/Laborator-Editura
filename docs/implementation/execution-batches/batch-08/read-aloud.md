# Read-Aloud

Read-aloud combines canonical text blocks, audio segments, timing, and reader
controls.

`TextAudioSyncSegment` links:

- publication.
- block.
- audio segment.
- start time.
- end time.
- sequence.

Children's read-aloud video composes illustrations, localized text, narration,
synchronization, timeline scenes, and captions. It must not recreate the book
manually in a separate video editor.
