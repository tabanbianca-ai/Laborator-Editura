# Multimedia Package

An approved multimedia package is immutable.

Package contents include:

- `multimedia-manifest.json`.
- rights manifest.
- accessibility manifest.
- integrity manifest.
- audio outputs.
- video outputs.
- transcripts.
- captions.
- illustrations.
- localized assets.
- validation evidence.
- checksums.

Packages are approved only when lineage, rights, accessibility, integrity, and
validation evidence pass.
