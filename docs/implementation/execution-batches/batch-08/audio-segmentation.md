# Audio Segmentation

Audio is generated by stable source block identifiers and chapter structure,
not only as one monolithic file.

`AudioSegment` records preserve:

- audio production.
- source blocks.
- sequence.
- text hash.
- voice profile version.
- generated audio asset.
- duration.
- status.

When source block hashes change, affected segments are marked `OUTDATED`.
Unchanged segments remain reusable and do not need unnecessary regeneration.
