# Video Production Model

`VideoProduction` is the canonical record for read-aloud, editorial video,
children's animated video, accessible video, and promotional video.

Supported video types:

- `READ_ALOUD`.
- `EDITORIAL_VIDEO`.
- `CHILDREN_ANIMATED`.
- `ACCESSIBLE_VIDEO`.
- `PROMOTIONAL_VIDEO`.

Every video production references the same canonical multimedia lineage as
audio. Video outputs remain derived artifacts and never become editorial
masters.
