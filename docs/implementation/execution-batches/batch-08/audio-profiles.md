# Audio Profiles

Audio configuration is stored in reusable `AudioProfile` records.

Profiles define:

- sample rate.
- bit depth.
- channels.
- target loudness.
- peak limit.
- speech rate.
- pause profile.
- chapter policy.
- output formats.
- normalization profile.

Initial output formats are `MP3` and `WAV`. New formats must be added through
profile metadata rather than hardcoded into editorial content.
