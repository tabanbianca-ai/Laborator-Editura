# Cost Tracking

External AI, TTS, and rendering work must create cost records.

Cost records preserve:

- provider.
- model.
- job.
- project.
- publication.
- input units.
- output units.
- cost.
- currency.
- timestamp.

Costs integrate with AI Cost Control and Observability. Required metrics
include TTS jobs, failure rates, render duration, accessibility failures,
illustration cost, and multimedia queue depth.
