# Localized Image Text

Required text inside illustrations should remain separate from canonical image
artwork whenever practical.

Preferred model:

Illustration + Localized Text Layer -> Localized Image Derivative.

This allows the same illustration to serve Romanian, English, Spanish, French,
Portuguese, Italian, German, and future languages without burning one language
permanently into the source image.

Legacy images with embedded text are preserved and localized through detected
or manually defined text regions.
