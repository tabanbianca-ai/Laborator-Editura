# Chunking And Embedding

Chunking profiles define strategy, token target, overlap, structural boundary preservation, citation requirements, and block id preservation.

Chunks must preserve block_id and source version.

Embedding records store collection id, source id, source version id, block id, content hash, embedding model id, vector status, rights reference, created time, and updated time.

Vectors become OUTDATED when source versions change or source content hashes no longer match.
