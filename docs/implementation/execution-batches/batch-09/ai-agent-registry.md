# AI Agent Registry

The AI Agent Registry is the canonical registry for production AI agents.

Each registered agent defines id, canonical name, type, purpose, owning module, allowed operations, tools, models, knowledge sources, required permissions, risk level, human review policy, status, and version.

Unregistered agents cannot execute production operations.

The 18 principal agents remain the only principal agent roles. Specialized subagents remain scoped under their parent agent and do not replace parent responsibility.

Human approval overrides every AI decision.
