# Legacy AI Migration

Legacy AI assets must be classified before migration.

Classifications are CANONICAL, LEGACY_AI, UNVERSIONED_PROMPT, DIRECT_PROVIDER_CALL, UNCONTROLLED_RAG, UNTRACKED_COST, RIGHTS_UNKNOWN, SECURITY_REVIEW_REQUIRED, and ORPHANED.

Legacy migration deletes nothing automatically.

Migration must preserve version history, audit history, source references, rights status, and human approvals.
