# Distribution Readiness

Distribution can start only when all required inputs are valid:

- approved publication package
- integrity
- rights
- territory
- language
- format
- channel compatibility
- mandatory metadata
- required identifiers
- commercial availability
- distribution approval

Derived statuses:

- READY_FOR_DISTRIBUTION
- MISSING_RIGHTS
- MISSING_METADATA
- CHANNEL_INCOMPATIBLE
- FORMAT_UNSUPPORTED
- TERRITORY_BLOCKED
- EXPIRED_RIGHTS
- BLOCKED
