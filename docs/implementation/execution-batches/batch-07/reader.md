# Reader

The digital reader supports:

- EPUB
- HTML
- structured text where rights permit
- chapter navigation
- table of contents
- bookmarks
- resume reading
- in-book search
- font adjustment
- text size
- line spacing
- contrast
- dark mode where supported by the design system
- screen reader
- keyboard navigation

PDF may be viewable separately, but it is not the only reading experience for
EPUB publications.
