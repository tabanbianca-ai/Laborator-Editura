# Migration Plan

Existing public resources must be inventoried before migration:

- sites
- pages
- stores
- links
- products
- reader accounts
- orders
- downloads
- integrations
- external identifiers

Classifications:

- CANONICAL
- LEGACY_PUBLIC_PAGE
- LEGACY_PRODUCT
- EXTERNAL_ONLY
- MAPPING_REQUIRED
- RIGHTS_REVIEW_REQUIRED
- UNKNOWN

Existing URLs must not be removed without controlled redirects.
