# Batch 07 Overview - Distribution, Public Application, Reader, Commerce And Withdrawal

Batch 07 establishes the canonical distribution, public application, reader,
commerce, entitlement, connector, synchronization, and withdrawal foundation.

Target flow:

Approved Publication Package -> Distribution Readiness -> Public Catalog ->
Reader / Download / Purchase -> Internal or External Distribution ->
Synchronization -> Monitoring -> Controlled Withdrawal.

Publication and distribution remain distinct processes. Approval of a
publication package does not automatically make it public, purchasable, or
externally distributed.

The public application does not own an independent editorial copy. It consumes:

- Unified Library.
- Approved Publication.
- Public Metadata.
- Rights and territory rules.
- Availability rules.
- Commercial configuration.

Editorial changes must happen in the canonical source and then be republished
through controlled publication and distribution.
