# Withdrawal

Withdrawal flow:

Withdrawal Request -> Impact Analysis -> Rights / Editorial / Legal Approval ->
Disable New Availability -> Withdraw Internal Catalog -> Withdraw External
Channels -> Reconciliation -> Reader Impact Handling -> Archive Evidence.

Withdrawal does not delete the publication.

Canonical reasons:

- RIGHTS_EXPIRED
- RIGHTS_REVOKED
- LEGAL_REQUEST
- CRITICAL_CONTENT_ERROR
- SECURITY_ISSUE
- PRIVACY_ISSUE
- SUPERSEDED
- EDITORIAL_DECISION
- CHANNEL_REQUIREMENT
- OTHER

Reader impact policy must be explicit for each withdrawal.
