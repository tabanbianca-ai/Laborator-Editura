## Immutable Baseline Rule

After v1.0 is certified, this snapshot becomes the immutable certified baseline.
Future changes must be classified as:

- `v1.0.x`: compatible bug and security fixes.
- `v1.1.x`: compatible new functionality and incremental improvements.
- `v2.0.0`: incompatible major changes with formal migration.

## v1.1 Planning Constraint

Codex v1.1 planning may be prepared now, but implementation is gated until the
v1.0 certification baseline is complete or the project owner explicitly
approves parallel planning work.
