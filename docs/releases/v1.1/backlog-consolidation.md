## Purpose

This document removes duplicate or overlapping v1.1 backlog language without
deleting source history.

## Consolidation Rules

- Preserve all source references.
- Keep one canonical backlog item per capability.
- Do not duplicate v1.0 modules.
- Treat implemented foundations as extension points, not as new modules.
- Move speculative or low-value work to later versions.
