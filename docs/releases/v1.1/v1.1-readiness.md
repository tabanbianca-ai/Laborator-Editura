# v1.1 Readiness

Status: BLOCKED_PENDING_V1_0_CERTIFICATION  
Owner: Release Management

## Current Decision

Codex v1.1 planning baseline is initialized, but v1.1 implementation is not
ready to start because the repository does not yet contain a certified v1.0
baseline.

## Definition of Ready

No v1.1 feature may enter implementation until it has:

- requirement;
- business value;
- owner;
- affected modules;
- dependencies;
- security impact;
- data impact;
- rights impact;
- accessibility impact;
- localization impact;
- acceptance criteria;
- required tests;
- migration strategy;
- rollback strategy.
