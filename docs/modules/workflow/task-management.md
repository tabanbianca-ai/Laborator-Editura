# Workflow Task Management

## Purpose

Workflow Task Management creates and coordinates actionable work generated by
workflow stages, transitions, deadlines, and automation rules.

Tasks are the bridge between process definitions and user execution surfaces
such as Work Table.

## Task Types

Workflow tasks may represent:

- Manuscript preparation.
- Translation.
- Editorial review.
- Proofreading.
- Rights validation.
- Layout.
- Illustration review.
- Audio review.
- Video review.
- Quality preflight.
- Publishing approval.
- Distribution readiness.
- Accessibility review.

## Current Repository Baseline

Current task-related support:

- Scheduling supports task records, events, reminders, agent run scheduling,
  conflicts placeholder, human approval, and audit.
- Editorial Pipeline guides users through production steps.
- Individual modules expose actions and statuses.

Gaps:

- Workflow Engine does not yet generate tasks from workflow definitions.
- Work Table is not fully driven by workflow-generated tasks.
- Assignment rules are not centralized.
- Task dependencies and SLA escalation are not centralized.

## Task Record

Each task should include:

- `taskId`.
- `workflowInstanceId`.
- `workflowVersionId`.
- `stateId`.
- `taskTemplateId`.
- `scopeType`.
- `scopeId`.
- `assigneeUserId`.
- `assigneeRole`.
- `assigneeTeamId`.
- `priority`.
- `status`.
- `dueAt`.
- `dependencies`.
- `comments`.
- `createdAt`.
- `completedAt`.

Task statuses:

- `PENDING`.
- `ASSIGNED`.
- `IN_PROGRESS`.
- `WAITING_FOR_APPROVAL`.
- `COMPLETED`.
- `BLOCKED`.
- `CANCELLED`.
- `OVERDUE`.

## Assignment Rules

Tasks may be assigned to:

- A user.
- A role.
- A team.
- A project role.
- A document owner.
- A reviewer pool.
- A publisher group.

Need-to-Know filtering must be enforced server-side for task details and
related resources.

## Completion Rules

Task completion may require:

- User action.
- Domain validation result.
- Approval.
- File/artifact presence.
- Workflow transition.
- Quality gate.

## Audit Requirements

Audit must record:

- Task created.
- Task assigned.
- Task reassigned.
- Task started.
- Task completed.
- Task blocked.
- Task overdue.
- Task cancelled.
