# Codex Standards Version Matrix

## Purpose

This matrix records standard versions and certified baseline status.

## Versioning Rule

All Codex standards use Semantic Versioning:

```text
MAJOR.MINOR.PATCH
```

Incompatible changes require a major version and migration plan. Approved
versions must not be overwritten.

## Change Requirements

Every future standard change must include:

- Justification.
- Impact analysis.
- Compatibility assessment.
- Migration plan.
- Approval.
- Audit record.

## Backward Compatibility Rule

A new or changed standard must not invalidate the certified Codex v1.0
baseline without an approved major version, compatibility plan, and migration
roadmap.
