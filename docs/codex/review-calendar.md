# Codex Standards Review Calendar

## Purpose

This calendar defines the review rhythm for Codex standards, frameworks,
policies, canonical models, specifications, guides, conventions, and approved
extensions.

## Review Rules

- Every standard must have a review cycle.
- High-risk standards require more frequent review.
- Review outcomes must be documented and audited.
- Review may result in reaffirmation, minor update, major update,
  deprecation, consolidation, or archival.
- Review does not authorize implementation by itself.

## Review Frequency

| Artifact type | Review frequency | Review owner |
| --- | --- | --- |
| Security, identity and access standards | Quarterly | Security Governance |
| AI governance and AI asset standards | Quarterly | AI Governance |
| Certification and compliance standards | Quarterly | Codex Governance |
| Data, API, workflow and integration standards | Semiannual | Architecture Governance |
| Documentation, lifecycle and configuration standards | Semiannual | Documentation and Platform Governance |
| Accessibility, localization, rights and publishing standards | Semiannual | Quality and Editorial Governance |
| Frameworks | Semiannual | Framework owners |
| Module specifications | Semiannual or before major release | Module owners |
| Root governance documents | Semiannual | Codex Governance |

## Codex v1.0 Review Baseline

| Review cycle | Scope | Target |
| --- | --- | --- |
| Initial certification review | Standards 01-21 | Codex v1.0 certification baseline |
| First post-certification review | Standards 01-21 and v1.1 roadmap | Before Codex v1.1 implementation freeze |
| Quarterly review | Security, AI, certification, compliance | Risk and exception review |
| Semiannual review | All standards and frameworks | Consolidation and compatibility review |
| Annual review | Full Codex governance corpus | Strategic architecture review |

## Review Outcomes

Allowed review outcomes are:

- `REAFFIRMED`.
- `MINOR_UPDATE_REQUIRED`.
- `MAJOR_UPDATE_REQUIRED`.
- `CONSOLIDATION_REQUIRED`.
- `DEPRECATION_RECOMMENDED`.
- `ARCHIVAL_RECOMMENDED`.
