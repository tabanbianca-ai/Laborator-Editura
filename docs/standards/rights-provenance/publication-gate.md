# Canonical Rights Publication Gate

## Purpose

This document defines the mandatory rights verification chain before
publication under Standard 13.

## Publication Verification Chain

Before publication, the system must verify:

```text
Resource selected
  -> Rights record found
  -> Rights holder verified
  -> Language authorized
  -> Territory authorized
  -> Format authorized
  -> Channel authorized
  -> Validity period confirmed
  -> Restrictions applied
  -> Publication approved
```

Any unclear result blocks publication.

## Expiration and Revocation

The system must:

- Monitor expiration dates.
- Warn before expiration.
- Block new publications after expiration.
- Identify affected publications.
- Allow controlled withdrawal.
- Preserve history.
- Notify responsible people.
- Trigger review.

Revocation does not delete rights history.

## Publication, Distribution and Promotion Separation

Publication and Distribution & Promotion are distinct processes:

- Publication produces the official edition.
- Distribution and promotion use only the validated official edition.
- Promotional materials are derivative assets.
- No independent copy of the edition is created for each channel.
- Metadata, rights, provenance, and history are reused.
- Promotional materials do not modify the official edition.

## Blocking Conditions

Publication is blocked when:

- Provenance is missing.
- Rights holder is not verified.
- Language is not authorized.
- Territory is not authorized.
- Format is not authorized.
- Channel is not authorized.
- Validity period is expired or unclear.
- Restrictions cannot be applied.
- Public domain status is ambiguous.
- Required consent is missing.
- AI content rights are unresolved.
