# Publication Metadata Requirements

## Purpose

Publication metadata identifies the official edition, its contributors, source
work, rights, formats, accessibility state, and distribution eligibility.

## Mandatory Metadata

Each published edition must include, when applicable:

- Title.
- Subtitle.
- Author.
- Translator.
- Editor.
- Proofreader.
- Illustrator.
- Narrator.
- Language.
- Original language.
- First publication year.
- Source edition.
- Edition number.
- Publisher.
- Publication date.
- ISBN.
- ISSN.
- Description.
- Categories.
- Keywords.
- Rights.
- License.
- Territories.
- Formats.
- Accessibility metadata.
- Original purchase or download link when required by policy or license.

## Identifier Support

The platform must support:

- `ISBN`.
- `ISSN`.
- `DOI`.
- `INTERNAL_PUBLICATION_ID`.
- `CHANNEL_PRODUCT_ID`.
- `EDITION_IDENTIFIER`.

External identifiers never replace the canonical internal identifier.

The same ISBN must not be assigned to incompatible formats or editions without
controlled policy review.

## Metadata Validation

Metadata validation must check:

- Completeness.
- Language and locale consistency.
- Contributor attribution.
- Original work attribution.
- Rights and license references.
- Accessibility metadata references.
- Format-to-edition compatibility.
- Distribution-channel requirements.
- Identifier uniqueness and applicability.

## Metadata Ownership

- Library owns canonical publication metadata.
- Publishing uses validated metadata for release.
- Distribution adapts metadata to channel requirements.
- Commerce adds commercial metadata without replacing publication metadata.
- Public Portal exposes approved public metadata only.
