# Publishing, Distribution and Withdrawal Consolidation Plan

## Purpose

This plan defines how existing publishing, distribution, export, public portal,
commerce, rights, accessibility, and Library records should converge toward
Standard 14 without destructive migration.

## Consolidation Principles

- Preserve existing identifiers.
- Preserve existing publication records.
- Preserve generated files and artifact references.
- Preserve distribution records.
- Preserve rights, accessibility, workflow, and approval evidence.
- Preserve audit history.
- Do not use external channel copies as canonical sources.
- Do not physically delete withdrawn or superseded publications through normal
  consolidation.

## Phase 1 - Inventory

Create a complete inventory of:

- Publications.
- Editions.
- Versions.
- Publication files.
- Export artifacts.
- Publication packages and manifests.
- Metadata records.
- Rights approvals.
- Accessibility validations.
- Distribution records.
- Channel mappings.
- External identifiers.
- Withdrawal and archive records.

## Phase 2 - Source-to-Output Lineage

Map each output to:

- Canonical work.
- Approved master document.
- Source master version.
- Workflow approval.
- Generation profile.
- Publication package.
- Derived format.
- Distribution record.
- Channel product identifier.
- Integrity record.

## Phase 3 - Compliance Reports

Produce:

- Metadata compliance report.
- Rights compliance report.
- Accessibility compliance report.
- Integrity compliance report.
- Distribution topology.
- Duplicate analysis.
- Orphan publication analysis.
- Withdrawal-readiness assessment.
- Risk register.

## Phase 4 - Canonical Package Alignment

Introduce canonical package manifests only after mapping:

- Existing Library publication records.
- Existing Publishing records.
- Existing Export artifacts.
- Existing Public Portal items.
- Existing Commerce editions.
- Existing Rights and Provenance records.
- Existing accessibility evidence.
- Existing audit records.

## Phase 5 - Connector Alignment

Align distribution channels with formal connector contracts:

- Internal Library.
- Public Portal.
- Owned store.
- Print On Demand.
- External bookstores.
- Audio platforms.
- Video platforms.
- Institutional channels.

## Phase 6 - Controlled Migration

Future implementation may add missing canonical fields or adapters only after:

- Impact analysis.
- Backward compatibility review.
- Backup/restore validation.
- Contract tests.
- Human approval.
- Rollback plan.

## Prohibited Consolidation

Do not:

- Delete historical publication records.
- Rename identifiers without compatibility mapping.
- Promote distributed files to master sources.
- Merge publication and distribution ownership.
- Bypass rights validation.
- Bypass accessibility validation.
- Bypass workflow approval.
- Bypass Human Final Authority.
