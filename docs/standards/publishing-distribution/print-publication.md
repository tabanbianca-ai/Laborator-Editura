# Print Publication Standard

## Purpose

Print publications are official editions generated from the approved master
through controlled layout, preflight, rights, metadata, and print profile
validation.

## Required Print Metadata

Print editions must preserve:

- Page format.
- Dimensions.
- Margins.
- Bleed.
- Color profile.
- Fonts used.
- Cover type.
- Page count.
- Recommended paper.
- Print profile.
- Provider.
- Final validated file.

The default European format may be A5, without excluding other configured and
approved sizes.

## Print Profiles

Print profiles must define:

- Region.
- Trim size.
- Bleed.
- Margins.
- Cover size.
- Spine width.
- Paper type.
- Color profile.
- Font embedding requirements.
- Crop marks.
- Provider compatibility.

## Print Validation

Print validation must check:

- Required print-ready PDF availability.
- Correct page size.
- Bleed and crop marks.
- Font embedding.
- Image resolution.
- Color profile.
- Cover dimensions.
- Spine width.
- Page count.
- Metadata and ISBN applicability.
- Rights for print and Print On Demand.

## Print Rules

- Print files must not be edited directly after approval.
- Print On Demand metadata is distribution metadata, not a source master.
- A print provider rejection does not automatically invalidate the official
  edition, but it must create auditable distribution status and remediation
  records.
