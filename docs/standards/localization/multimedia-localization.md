# Canonical Multimedia Localization Standard

## Purpose

This document defines localization rules for multimedia assets under Standard
11.

## Applies To

The standard applies to:

- Subtitles.
- Transcripts.
- Audio descriptions.
- Text embedded in images.
- Narration.
- Multilingual audio files.
- Video materials.
- Accessibility metadata.

## Required Linkage

Every localized multimedia variant must remain linked to:

- Source asset.
- Source version.
- Language and locale.
- Translator, narrator, contributor, or AI agent where applicable.
- Approval record.
- Rights and usage metadata.
- Accessibility metadata where applicable.

## Separation Rules

- Multimedia localization must not duplicate editorial source content.
- Localized media derivatives must reference the canonical master asset.
- Draft preview assets must not be treated as published assets.
- AI-generated localized media remains advisory until approved by authorized
  humans where approval is required.

## Validation Rules

Multimedia localization validation must check:

- Subtitle language and timing.
- Transcript completeness.
- Audio language and voice metadata.
- Text embedded in image variants.
- Accessibility metadata.
- Rights metadata.
- Source version linkage.
- Publication approval status.

## Relationship to Media Localization Studio

Media Localization Studio remains the future operational capability for media
localization workflows. Standard 11 defines the canonical localization rules
that such workflows must follow.
