# Canonical EPUB Accessibility Standard

## Purpose

This document defines accessibility requirements for EPUB outputs under
Standard 12.

## Accessible EPUB Requirements

Every accessible EPUB must include:

- Semantic structure.
- Reading order.
- Navigation by chapters and sections.
- Accessibility metadata.
- Declared language.
- Alternative text.
- Accessible tables.
- Navigable notes and references.
- Compatibility with assistive reading systems.
- Automated validation before publication.

## Validation Requirements

EPUB validation must check:

- Package metadata.
- Table of contents.
- Landmark navigation where applicable.
- Language declarations.
- Reading order.
- Alternative text coverage.
- Link accessibility.
- Notes and references.
- Embedded media accessibility.

## Evidence Requirements

EPUB accessibility validation must preserve:

- Source manuscript or publication.
- Source version.
- EPUB artifact identifier.
- Export profile.
- Validation result.
- Tool or reviewer.
- Violations and warnings.
- Evidence.
- Approval where required.
