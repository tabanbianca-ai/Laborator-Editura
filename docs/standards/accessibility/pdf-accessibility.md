# Canonical PDF Accessibility Standard

## Purpose

This document defines accessibility requirements for PDF outputs under
Standard 12.

## Accessible PDF Requirements

Accessible PDFs must include:

- Tagged structure.
- Correct reading order.
- Title and language.
- Hierarchical headings.
- Navigation bookmarks.
- Alternative text.
- Correctly tagged tables.
- Descriptive links.
- Sufficient contrast.
- Compatible fonts and encoding.
- PDF/UA validation when publication policy requires it.

## Non-Compliant PDF Pattern

A visually correct PDF without semantic structure is not considered
accessible.

## Evidence Requirements

PDF accessibility validation must preserve:

- Source document.
- Source version.
- Export profile.
- PDF artifact identifier.
- Validation tool or reviewer.
- Validation result.
- Violations and warnings.
- Remediation status.
- Evidence files.
- Approval when required.

## Relationship to Publishing

Publishing and Distribution must expose PDF accessibility readiness when PDF
output is part of the publication package.

Blocking PDF accessibility findings must prevent release when policy marks
the output as accessibility-required.
