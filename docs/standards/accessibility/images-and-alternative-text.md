# Canonical Images and Alternative Text Standard

## Purpose

This document defines image classification and alternative text rules under
Standard 12.

## Image Classifications

Every image must be classified as:

- `INFORMATIVE`.
- `DECORATIVE`.
- `FUNCTIONAL`.
- `COMPLEX`.
- `TEXTUAL`.

## Rules by Classification

| Classification | Requirement |
| --- | --- |
| `INFORMATIVE` | Provide meaningful alternative text |
| `DECORATIVE` | Hide from assistive technology |
| `FUNCTIONAL` | Describe the action or function |
| `COMPLEX` | Provide short alt text and extended description |
| `TEXTUAL` | Provide equivalent text content |

## AI-Generated Alternative Text

AI may propose alternative text, captions, or descriptions.

AI-generated alternative text requires human validation before publication
according to risk level.

## Visual Content Rules

Visual content must:

- Avoid unnecessary embedded text in images.
- Provide text alternatives for charts and diagrams.
- Provide descriptions for complex editorial illustrations.
- Remain understandable for color vision deficiencies.
- Not communicate information through color alone.

## Audit Requirements

Alternative text decisions must preserve:

- Source asset.
- Asset version.
- Classification.
- Proposed text.
- Reviewer.
- Approval status.
- AI source where applicable.
- Audit reference.
