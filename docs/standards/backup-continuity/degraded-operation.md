# Degraded Operation Standard

## Purpose

Degraded operation allows limited, controlled platform use when not all
services are available.

## Allowed Degraded Capabilities

In degraded mode, the platform may allow controlled:

- Consultation of already available publications.
- Limited document access.
- Suspension of multimedia generation.
- Suspension of new publication.
- Deactivation of non-essential integrations.
- Limitation of AI operations.
- Read-only operation.

## Degraded Operation Rules

- Degraded mode must not allow uncontrolled loss of changes.
- Degraded mode must not bypass Need-to-Know.
- Degraded mode must not bypass rights restrictions.
- Degraded mode must not bypass Human Final Authority.
- Degraded mode must preserve audit where writes remain available.
- When writes are disabled, the system must clearly communicate read-only
  behavior.

## Exit Criteria

Exit from degraded mode requires:

- Restored core services.
- Validated data consistency.
- Reconciled temporary manual work.
- Confirmed audit continuity.
- Communication to affected users.
- Closure record.
